# Проверка оформления репозитория

Проверено по перечню из задания варианта 8. Проверка относится ко всем
отслеживаемым файлам итогового коммита; временные результаты примеров
создавались вне репозитория и удалялись после ручного запуска.

| Пункт | Проверка | Результат |
| --- | --- | --- |
| С1 | `README.md` в корне | Есть; содержит описание, функции, запуск и примеры. |
| С2 | `.gitignore` в корне | Есть; игнорирует кэш, сборку, редакторы и вывод. |
| С3 | Каталог `src` | Есть; содержит разбор, запись TOML и CLI. |
| С4 | Каталог `tests` | Есть; проверки синтаксиса, констант, CLI и примеров. |
| С5 | Скрипт запуска | Есть `run.bat`. |
| С6 | Сообщения коммитов | Используется формат `type(scope): description`. |
| Г1 | Архивы | Отсутствуют в `git ls-files`. |
| Г2 | Бинарные файлы | Отсутствуют в `git ls-files`. |
| Г3 | Служебные файлы Python | `__pycache__` и `*.py[cod]` игнорируются. |
| Г4 | Артефакты сборки | `build`, `dist`, `output` игнорируются. |
| Г5 | Настройки редактора | `.idea` и `.vscode` игнорируются. |
| Р1 | Файлы длиннее 1000 строк | Наибольший исходный файл короче 120 строк. |
| Р2 | Строки Python длиннее 80 | Проверка длины строк нарушений не нашла. |
| Р3–Р5 | JavaScript, Kotlin, Rust | Кода на этих языках нет. |
| Р6 | Строки кода длиннее 120 | Отсутствуют, поскольку строки Python не длиннее 80. |
| Ф1 | Функции Python длиннее 40 строк | Наибольшая функция короче 30 строк. |
| Ф2–Ф7 | Другие языки | Функций на этих языках нет. |
| А1 | Более 7 аргументов у функции Python | Не более 3 аргументов. |
| А2–А7 | Другие языки | Функций на этих языках нет. |
| К1 | Комментарии вместо docstring | У модулей, классов и функций есть docstring. |
| К2–К7 | Другие языки | Кода на этих языках нет. |
| Ц1 | Сложность функций Python выше 10 | Максимум 7 по подсчету ветвлений AST. |
| Ц2–Ц7 | Другие языки | Кода на этих языках нет. |
| М1 | Числа в сравнениях Python | Не найдены при проверке дерева AST. |
| М2–М7 | Другие языки | Кода на этих языках нет. |
| И1 | Имена Python | Функции и переменные `snake_case`, классы `PascalCase`. |
| И2–И7 | Другие языки | Кода на этих языках нет. |

Проверка работы: `python -B -m unittest discover -s tests -v`.
Также вручную запущены три примера через `run.bat`; все временные
выходные файлы удалены. Перед коммитом выполнен `git diff --check`.
