# Транслятор конфигураций — ДКР, вариант 8

Консольная программа читает учебный конфигурационный язык из стандартного
ввода и записывает TOML в файл, заданный флагом `-o` / `--output`.
Синтаксис разбирает специализированная библиотека Lark (алгоритм LALR).
Поддерживаются числа, вложенные словари, оба вида комментариев и
вычисляемые на этапе трансляции константы. История из четырех коммитов
показывает постепенное развитие работающего инструмента.

## Установка и запуск

Нужен Python 3.11 или новее. Сборка не требуется. Из корня репозитория:

```text
python -m pip install -r requirements.txt
python -B -m src.cli --output output/result.toml < input.txt
run.bat --output output\result.toml < input.txt
python -B -m unittest discover -s tests -v
```

Флаг `--output` обязателен. Относительный путь считается от текущего
каталога. Вход читается как UTF-8, выход записывается как UTF-8.
Родительские каталоги результата создаются автоматически. При
синтаксической ошибке программа сообщает строку и столбец в stderr
и возвращает код 1. Файл заменяется атомарно после успешной проверки.
Команда с `<` рассчитана на `cmd` и другие оболочки с перенаправлением.
В PowerShell используйте `Get-Content -Raw -Encoding UTF8 input.txt |
python -B -m src.cli -o output/result.toml`.

## Поддерживаемый синтаксис

- Однострочный комментарий начинается с `*` и длится до конца строки.
- Многострочный комментарий заключен между `#[` и `]#`.
- Число имеет вид `\d+\.\d*`, например `1.0` или `2.`.
- Имена состоят из латинской буквы и латинских букв или цифр далее.
- Словарь содержит пары `имя = значение`, разделенные запятыми.
  Значением бывает число, вложенный словарь или ссылка `^(имя)`.
  Конечная запятая допустима.
- `def имя := значение` объявляет константу до корневого словаря.
  Объявления допустимы и внутри словарей как элементы через запятую.
  Значение вычисляется сразу, поэтому ссылки на еще не объявленное имя
  вызывают ошибку. Локальное объявление действует в своем словаре и
  вложенных словарях, но не за его пределами.
- Корень входного документа — словарь; он превращается в таблицы TOML.

Числа нормализуются для TOML: `0002.` становится `2.0`.
Повторяющиеся ключи и объявления в одной области считаются ошибкой.

## Устройство программы

| Функция | Назначение |
| --- | --- |
| `parse_source` | Разобрать полный вход в дерево Lark или сообщить место ошибки. |
| `normalize_number` | Привести десятичную запись к синтаксису TOML. |
| `name_token` | Получить имя и его позицию из дерева Lark. |
| `define_constant` | Вычислить объявление и проверить повтор имени в области. |
| `evaluate_dictionary` | Вычислить поля и локальные объявления словаря. |
| `evaluate_value` | Вычислить число, словарь или ссылку `^(имя)`. |
| `translate_source` | Получить итоговый словарь из дерева документа. |
| `render_table` | Записать поля и рекурсивно вложенные таблицы TOML. |
| `to_toml` | Вернуть полный текст TOML. |
| `write_output` | Записать результат во временный файл и атомарно заменить выход. |
| `main` | Прочитать stdin, разобрать параметры и вернуть код результата. |

Грамматика находится в `src/parser.py`, сериализация в
`src/toml_writer.py`, запуск в `src/cli.py`. Дополнительных настроек,
кроме обязательного пути `-o` / `--output`, нет.

## Пример

```text
#[ настройки сервиса ]#
{
    port = 8080.0,
    limits = { requests = 12.5, timeout = 2. },
}
```

Результат:

```toml
port = 8080.0

[limits]
requests = 12.5
timeout = 2.0
```

## Три предметные области

Файлы `examples/server.conf`, `examples/experiment.conf` и
`examples/budget.conf` описывают соответственно сервер, лабораторный
эксперимент и бюджет подразделений. Они используют комментарии,
вложенные словари и переиспользование констант. В примере бюджета
локальное значение ставки `10.0` действует только внутри `training`;
для `research` и `standardTax` остается глобальное `20.0`.

Запуск каждого примера из `cmd` или Bash:

```text
python -B -m src.cli -o output/server.toml < examples/server.conf
python -B -m src.cli -o output/experiment.toml < examples/experiment.conf
python -B -m src.cli -o output/budget.toml < examples/budget.conf
```

Результаты в `output/` не включаются в Git. Проверка примеров
автоматизирована в `tests/test_examples.py` и сравнивает все значения
полученного TOML с ожидаемыми.
